# Realm Conquest - Medieval Edition

A real-time multiplayer-style territory conquest game inspired by classic io mechanics (such as Paper.io), built from scratch using **HTML5 Canvas** and **JavaScript**. Designed with custom UI scaling, smooth grid-based logic, and intelligent bot AI.


## 🚀 Key Features

* **Grid-Based Territory Capture:** Custom algorithm for flooding and capturing unowned/opponent territory upon returning safely to home base.
* **Autonomous Bot AI:** Dynamic AI states (Base roaming, expedition raids, and automated retreat behaviors) to challenge the player.
* **Custom UI & HUD Integration:** Styled medieval user interface with dynamic speed metrics and real-time leaderboard tracking.
* **Optimized Rendering System:** Offscreen buffer canvas masking for seamless texture mapping over conquered areas.
* **Audio-Visual Feedback:** Procedural sound synthesis using Web Audio API for interactive gameplay events.

## 🛠️ Technologies Used

* **JavaScript (ES6+)**: Core game loop, collision detection, and state machine architecture.
* **HTML5 Canvas**: High-performance 2D rendering and pixel/grid manipulation.
* **CSS3**: Medieval-themed UI design, flexbox layouts, and custom asset frames.
